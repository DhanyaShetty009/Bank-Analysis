# Bank Analysis Dashboard

This repository contains a complete **Bank Analysis** project using **SQL** for data extraction and **Tableau** for data visualization. The goal of this project is to analyze key banking metrics and generate insightful, interactive dashboards for business decision-making.

---

## Project Overview

The project is structured into two major components:

### 1. SQL Data Analysis
- Data extraction, cleaning, and transformation using SQL queries
- Analysis of:
  - Customer data
  - Transactions
  - Loan disbursements
  - Credit and default metrics

### 2. Tableau Dashboard
- Interactive dashboards built using Tableau
- Key visual insights on:
  - Customer segmentation
  - Branch performance
  - Loan and recovery analysis
  - Financial KPIs

---

## Files Included

- `bank analysis.sql`: Contains SQL scripts used for data querying and preprocessing
- `Bank Analysis.twbx`: Tableau workbook with final dashboards and visuals

> **Note**: You need:
> - A SQL environment (e.g., MySQL, PostgreSQL, or SQL Server) to run `.sql` scripts  
> - Tableau Desktop to view `.twbx` files
